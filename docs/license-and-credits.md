### Third-Party Libraries and Tools

The project relies on and acknowledges the following key open-source libraries and tools:

- **ROS 2 (Robot Operating System 2):** The middleware framework enabling modular robotics software development.  
  [https://docs.ros.org/en/foxy/](https://docs.ros.org/en/foxy/)

- **XICRO:** Tool for generating ROS 2 nodes and firmware for Arduino-based servo control.  
  Repository: [https://github.com/aalonsopuig/Xicro-enhanced](https://github.com/aalonsopuig/Xicro-enhanced)

- **OpenCV:** Library used for image processing and face detection.  
  [https://opencv.org/](https://opencv.org/)

- **Dlib:** Machine learning toolkit providing face recognition and facial landmark detection.  
  [http://dlib.net/](http://dlib.net/)

- **Piper TTS:** Neural text-to-speech engine for offline voice synthesis.  
  [https://rhasspy.github.io/piper/](https://rhasspy.github.io/piper/)

- **Other ROS 2 standard packages:** Including `rclpy`, `std_msgs`, and supporting utilities.
